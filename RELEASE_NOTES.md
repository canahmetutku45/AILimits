Your Claude, ChatGPT/Codex and Antigravity plan limits, live on the Windows taskbar.

### Install
1. Download **AILimits.exe** below and double-click it.
2. If Windows shows "Windows protected your PC", click **More info → Run anyway**. The app
   isn't code-signed yet; see the [code signing policy](https://github.com/canahmetutku45/AILimits#code-signing-policy).
3. The installer shows what it will do (start with Windows, Start menu shortcut, keep
   sign-ins fresh), and you can turn each one off. No admin rights needed.

### Before you install
- **Taskbar must be at the bottom of the screen.** Left/right/top taskbars aren't supported yet.
- **Turn off Windows Widgets** (the weather on the taskbar): Settings → Personalization →
  Taskbar → Taskbar items → Widgets off. AI Limits sits in that spot.

### Every release is built from source

from the tagged source code in this repository.
